10. How to add machine permit?


Easy Steps:

 

1. Click BIR->Machine Permits

2. Click New

3. Select Computer Name (Click New)

4. Input other details

    Permit No - Permit No from the BIR

    RDO Code - BIR RDO Code

    Date Issued  & Expiry Date of the Permit

    SerialNo - Serial number of the computer

    MachineNo - Machine number of the computer

    Sales Invoice Prefix, Start Number and End Number

    Sales Return Prefix, Start Number and End Number

5. Click Save
