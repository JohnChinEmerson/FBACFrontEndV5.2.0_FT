Items


    A. Click Files->Items

    • View - to view items
    • New - to add new item
    • Print - to print items
    • Barcoding - add barcode to items

 

    B. Select HasRepackSource - to view items with repack source

 

    C. How to add new item?

        Easy Steps:

1. Click Files->Items

2. Click New button

3. Fill-in textboxes

   Item - item name or description

    Cost - supplier price of the item

    Price  - selling price of the item

    VATType - item VAT type for taxing purposes.

    HasInventory - no if qty is not inventoried

    Consumable - no if item is a fixed asset.

    AlertQty - out of stock set quantity.

    For Sale - no if item is not for sale.

   UM - item unit of measure (i.e. pc,pck, kg, ltr,btl etc.)

   Category - classify items in terms of category (i.e. shampoo, biscuits, paracetamol etc.)

   Item Type - classify items in terms of type ( item, menu, office supplies, etc)

4. Click Save

 

D. How to edit/delete item?

     Easy Steps:

1. Search Item

2. RightClick->Select edit/delete

E. How to add item price category?

     Easy Steps:

1. Search Item

2. RightClick->Select Price Category

3. Click New Price Category

    3.1 Input Price Category->Press Enter (right click to delete price category)

    3.2 Close Window

4. Input Price under Price column

5. Input Minimum Quantity under MinimumQty column (optional)

6. Click Save

F. How to add item repack source?

     Easy Steps:

1. Search Item

2. RightClick->Select Repack Sources

3. Click New

    3.1 Input Item Repack Source

    3.2 Input Equivalent Qty

    3.3 Click Save

    3.2 Close Window

...right click record to edit/delete repack source

4. Close Window

G. How to transfer item qty from repack source?

     Easy Steps:

1. Search Item

2. RightClick->Select Repack Sources

3. RightClick Record->Click Repack

    3.1 Input Qty

    3.2 Choose Expiry (optional)

    3.3 Click Save

H. How to add item expiry dates?

     Easy Steps:

1. Search Item

2. RightClick->Select Expiry Dates

3. Click New

    3.1 Select ExpiryDate

    3.2 Input BatchLotNo

    3.3 Input Qty

    3.4 Click Save

    3.5 Close Window

I. How to edit/delete item expiry dates?

     Easy Steps:

1. Search Item

2. RightClick->Select Expiry Dates

3. Search ExpiryDate/BatchLotNo

4. RightClick->Select edit/delete

J. How to add/delete item serial numbers?

     Easy Steps:

1. Search Item

2. RightClick->Select SerialNos

3. Select Warranty Date (optional)

4. Scan/Input SerialNo->Click Add

...to delete

1. RightClick->Select delete

K. How to add/remove item barcode?

     Easy Steps:

1. Search NoBarcode Item->Press Enter

2. Scan/Input Barcode->Press Enter

...to remove

1. Search WithBarcode->Click Remove

 

K. Web version

  • Upload Items - to add many items from an Excel file
  • 1. Click Files->Items->Upload Items
  • 2. Click ItemsFormat to download the template and fill it in (one sheet per item type and a Costing sheet)
  • 3. Choose the file->Click Check File - items that already exist are skipped; nothing is uploaded until the errors shown are fixed
  • 4. Click Upload
  • Export Items - to export the items
  • RightClick item->Photo - to set the picture of the item
  • RightClick item->AveCost History - to view the cost history of the item. AveCostMethod of the item: Average Costing Method, Last Highest Item Cost or Last Purchase Cost.
  • Branch Update - shown in the main branch: updates the items in the other branches
