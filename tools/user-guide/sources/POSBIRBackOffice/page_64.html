Stock Totals

      A. Click Inventory->Stock Totals

    • View - to view stock totals
    • Print- to print stock totals
    • Adjust Price - to adjust price based on category

           1. Select Category

           2. Input Markup in percent/amount

           3. Check/Uncheck Round Price Result to Whole Number

           4. Click Ok
