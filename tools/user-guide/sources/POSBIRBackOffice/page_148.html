Adjustment Transaction


Easy Steps:

 

1. Click StockAdjustments->Adjustment Transaction

2. Select adjustment type

3. Search adjustment reason

4. Search Item->Press Enter

5. Input Quantity->Press Enter

...repeat the process until all stocks are entered.

...right click the stock to add serialnos, edit/remove (second tab)

6. Click Save-F2

7. Select ReportAs

8. Click Save
