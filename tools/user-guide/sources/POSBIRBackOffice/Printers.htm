Printers


    A. Click Files->Printers

    • New - to add new printer
    • Edit - to edit printer 
    • Delete - to delete printer

    B. How to add new printer?

        Easy Steps:

1. Click Files->Printer

2. Click New button

3. Locate PrinterName

     In the Windows taskbar, search for Printers & Scanners and open it.

     Browse through the list of printers connected to your network and select the one you want to add.

4. Fill in the Printer Details

     Area - Enter the location of the printer (e.g., "Office 1" or "Reception").

     PrinterName - Enter the exact name of the printer as listed in your computer.

        5. ClickSave

      C. How to edit/delete printer?

          Easy Steps:

        1. Search Printer

        2. Click Edit button for edit and Delete button for delete.

 

     D. How to view assigned items for a printer?   

          Easy Steps:

        1. Select a Printer: Choose a printer from the first panel.

        2. View Assigned Items: The second panel will display all items currently assigned to the selected printer.

 

     E. How to remove/remove all assigned items from a printer?   

          Easy Steps:

        1. Select a Printer: Choose a printer from the first panel.

        2. View Assigned Items: The second panel will display all items currently assigned to the selected printer.

        3. Click Remove or Remove All button to remove item from printer.

 

     F. How to assign items to a printer?   

          Easy Steps:

        1. Select a Printer: Choose a printer from the first panel.

        2. View Assigned Items: The second panel will display all items currently assigned to the selected printer.

        3. View Unassigned Items: Click the View button in the third panel to see items not assigned to any printer.

        4. Select Items: Check the boxes next to the items you want to assign to the selected printer.

        5. Select All Items: Use the Check All button to select all items at once.

        6. Filter by Category: Choose a category to view items specific to that category.

        7. Assign Items: Click the Assign button to complete the process.
