Payment Receipts

 
     Click Receivables->Payment Receipts

    • Select DateRange->Click Go - to view payment transactions
    • Print - to print payment receipts
    • Search - to search receipt
      • RightClick selected record to view accounting entry or edit/void receipt
    • View Details - to view selected receipt
      • RightClick selected record to view edit/void invoice
    • View All Details - to view the details of all the receipts based on the selected date range
      • RightClick selected record to view edit/void invoice
