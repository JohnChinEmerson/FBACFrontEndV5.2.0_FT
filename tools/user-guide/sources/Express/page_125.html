Customer Checks


Click Cashflow->Customer Checks

    • Select Filter Criteria->Click Go
    • Print - to print customer checks
    • New - to add new customer check

      1. Search Customer

      2. Input BankName and CheckNo

      3. Input Amount and CheckDate

      4. Click Save

    • Search - to search customer check

    • Deposit - to deposit customer check

  • Web version - filter the checks by Status, Month and Year. Select checks and click Deposit / Undeposit to deposit or undeposit them.
