Cashiering Records

 
     Click Cashiering->Cashiering Records

    • Select DateRange->Click Go - to view cashiering records
    • Print - to print cashiering records
    • Search - to search record
    • View Ledger- to view record ledger
    • Reading Details - to view record reading details
    • CashReadings - to CashReadings
      • Select DateRange->Deposited/Undeposited->Click Go
      • Print - to print cash reading
      • Deposit - to deposit cash
      • Withdraw - to withdraw cash
      • Search - to search cash reading
      • View Ledger- to view cash ledger
      • Reading Details - to view cash reading details
