Payees


A. Click Expenses->Payees

  • View - to view payees
  • New - to add new payee. Fill-in textboxes: PayeeName, Address, ContactNo, TermDays, PayeeTIN, BusinessStyle->Click Save
  • Print - to print payees
  • RightClick selected payee->Edit / Delete
