Cash Transfers

 
     Click Cash Transfers->Cash Transfers

    • Select DateRange->Click Go - to view cash transfer transactions
    • Print - to print cash transfer transactions
    • New Cash Transfer - to add new cash transfer transaction

          1. Select Source

          2. Select Destination

          3. Input Amount

          4. Click Save

    • Search - to search cash transfer transaction
      • RightClick selected record to view accounting entry, edit/void cash transfer transaction
