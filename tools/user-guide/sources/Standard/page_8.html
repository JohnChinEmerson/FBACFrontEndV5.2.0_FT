15. How to transact charge sales and receivable payments?


Easy Steps:

 

1. Click Sales->Sales Transaction

2. Search Item->Press Enter

...repeat the process until all items entered

3. Click Save-F4

4. Select PaymentType Charge

5. Click Save

 

6. Click Receivables->Payment Transaction

7. Select Customer

8. Right Click Record->Click Add

9. Input AmountPaid->Press Enter / Click Save
