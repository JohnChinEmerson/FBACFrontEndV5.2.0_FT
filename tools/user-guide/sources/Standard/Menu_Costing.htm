Menu Costing


    A. Click Menu ->Menu Costing

    • View - to view items for costing 
    • Components- set up menu costing
    • Print - to print items for costing

 

    B. Filter by ItemType: Choose a item type to view items specific to that item type.

 

    C. How to set up menu costing?

        Easy Steps:

1. Select Item and Add Components

        Choose the item to cost, then click Components.

2. Click View button from first panel to view unassigned components.

3. Add Ingredients and Quantity

      Select all required ingredients .

      SetQtyMade based on expected output.

      For each ingredients inputQtyUsed based on QtyMade amount.

4. Adjust Unit of Measure ( UM)

      If UM differs between receiving and costing, double-click UM to adjust.

5. Calculate Cost

      The system will auto-calculate the cost per finished product.

6. Set Price

      Close, then click the Price column to edit.

7. Ready for Transaction

    D. How to remove/remove all assigned components?    

         Easy Steps:

        1.Select a Component: Choose a component from the second panel.

        2. Click Remove or Remove All button to remove item from printer.

 

E. Web version

  • When items are received (Receiving Transaction) the costing of the menu is updated automatically: a component that is received at a higher cost than the menu uses takes the new cost, and the cost of the menu is computed again. A lower cost never reduces the cost of a menu. Every change is kept in the menu costing history.
