Adjusting Entries

 
     Click Accounting->Adjusting Entries

    • Select DateRange->Click Go - to view adjusting entries
    • Print - to print cash adjusting entries
    • New Entry- to add new adjusting entries     

           1. Select TransactionType

           2. Input Description->AccountTitle->Debit/Credit

            ...repeat the process until all adjusting entries are entered.

           3. Click Save
    • Search - to search cash adjusting entry
      • RightClick selected record to edit/delete adjusting entry
