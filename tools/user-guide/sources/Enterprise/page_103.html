PO Transaction


Easy Steps:

 

1. Click Purchasing->PO Transaction

2. Select Supplier

3. Search Item->Press Enter

4. Input Quantity->Press Enter

...repeat the process until all items entered

...right click the item to edit/remove (second tab)

5. Click Save-F4

6. Select PaymentType

7. Check Request Voucher (if supplier request advance payment)

8. Click Save

 

Web version

  • The header window shows the VAT details of the purchase order (VATSales, VATExemptSales, VATAmount), the same as the sales receipt.
