16. How to transact charge receiving and payable payments?


Easy Steps:

 

1. Click Receiving->Receiving Transaction

2. Search Item->Press Enter

3. Input Quantity->Press Enter

...repeat the process until all items entered

4. Click Save-F4

5. Select PaymentType Charge

6. Click Save

 

7. Click Payables->Payee Transaction

8. Select Payee

9. Right Click Record->Click Add

10. Select PaymentType 

11. Click Save
