20. How to transact purchase order with Advance Payment?


Easy Steps:

 

1. Click Purchasing->PO Transaction

2. Select Supplier

3. Search Item->Press Enter

4. Input Quantity->Press Enter

...repeat the process until all items entered

5. Click Save-F4

6. Select PaymentType

7. Check Request Voucher

8. Click Save

 

9. Click Vouchering->Voucher Requests

10. Click View Requests

11. Select Receipt

12. Click Action->Generate Voucher

13. Select PaymentType

14. Input Amount

15. Input Requested By

16. Click Save

 

17. Click Disbursement->Disbursement Requests

18. Click View Requests

19. Select Receipt

20. Click Action->Generate Disbursement

21. Select PaymentType

22. Select CashAccount

23. Input Received By

24. Click Save
