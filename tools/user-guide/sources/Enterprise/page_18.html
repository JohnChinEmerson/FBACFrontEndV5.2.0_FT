25. How to transact payable payment with disbursement?


Easy Steps:

 

1. Click Payables->Payee Transaction

2. Select Payee

3. Right Click Record->Click Add

4. Select PaymentType 

5. Click Save

 

6. Click Disbursement->Disbursement Requests

7. Click View Requests

8. Select Receipt

9. Click Action->Generate Disbursement

10. Select PaymentType

11. Select CashAccount

12. Input Received By

13. Click Save
