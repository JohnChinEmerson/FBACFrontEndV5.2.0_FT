Delivery Receipts

 
     Click Delivery->Delivery Receipts

    • Select DateRange->Click Go - to view delivery transactions
    • Print - to print delivery receipts
    • Search - to search receipt
      • RightClick selected record to add item or edit/void receipt
    • View Details - to view selected receipt
      • RightClick selected record to view serialnos or edit/void item
    • View All Details - to view the details of all the receipts based on the selected date range
      • RightClick selected record to view serialnos or edit/void item
