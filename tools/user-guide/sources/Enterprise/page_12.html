19. How to transact order-sales-delivery Transaction?


Easy Steps:

 

1. Click Orders->Order Transaction

2. Select Customer

3. Search Item->Press Enter

...repeat the process until all items entered

4. Click Save-F4

5. Input DownPayment ->Press Enter / Click Save

 

6. Click Sales->Sales Transaction

7. Right Click Empty Space at the second tab

8. Click Load S.O. button

9. DoubleClick selected Sales Order record

10. Click Save-F4

11. Change Pickup dropdown to Deliver

12. Select PaymentType

13. Click Save

 

14. Click Delivery->Delivery Transaction

15. Click Go

16. Select Receipt

17. Click Save-F4

18. Fill in Remarks

19. Click Save
