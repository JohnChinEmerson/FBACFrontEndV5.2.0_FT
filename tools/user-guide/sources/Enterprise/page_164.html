Voucher Requests


1. Click Vouchering->Voucher Requests

2. Click View Requests

3. Select Receipt

4. Click Action->Generate Voucher

5. Select PaymentType

6. Input Amount

7. Input Requested By

8. Click Save

... Voucher will be queued under Disbursements->Disbursement Requests
