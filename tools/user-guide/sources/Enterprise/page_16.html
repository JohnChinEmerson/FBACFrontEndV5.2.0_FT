23. How transact receiving with disbursement?


Easy Steps:

 

1. Click Receiving->Receiving Transaction

2. Search Item->Press Enter

3. Input Quantity->Press Enter

...repeat the process until all items entered

4. Click Save-F4

5. Select PaymentType (Except Charge)

6. Select FundSource->Disbursement

7. Click Save

 

8. Click Disbursement->Disbursement Requests

9. Click View Requests

10. Select Receipt

11. Click Action->Generate Disbursement

12. Select PaymentType

13. Select CashAccount

14. Input Received By

15. Click Save
