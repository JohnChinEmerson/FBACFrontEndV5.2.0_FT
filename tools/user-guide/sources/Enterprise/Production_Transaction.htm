Production Transaction


Easy Steps:

 

1. Click Menus-> ProductionTransaction

2. Search Item->Press Enter

3. Input Quantity->Press Enter

...repeat the process until all items entered

...right click the item to edit/remove and remove all (second tab)

4. Click Save-F2

5. Select TransDate

6. Click Save
