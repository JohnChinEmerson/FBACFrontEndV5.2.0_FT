17. How to transact charge expenses and payable payments?


Easy Steps:

 

1. Click Expenses->Expense Transaction

2. Search Particular->Press Enter

3. Input Amount->Press Enter

...repeat the process until all particulars entered

4. Click Save-F4

5. Select PaymentType Charge

6. Click Save

 

7. Click Payables->Payee Transaction

8. Select Payee

9. Right Click Record->Click Add

10. Select PaymentType 

11. Click Save
