6. How to sale item?


Easy Steps:

 

1. Click Sales->Sales Transaction

2. Select Table

3. Select Category

4. Select Item

    ...repeat the process until all items entered

5. Choose DINE IN or TAKE OUT

6. Click SEND to send the order to the kitchen.

7. Click SERVE when the order is served to the customer.

8. Click PAY->Input AmountPaid->Press Enter / Click Save

9. Click COMPLETE to make the table available for the next transaction.
