4. How to setup menu costing?


Easy Steps:

 

1. Click Menus->Menu Costing

2. Select Item and Add Components

        Choose the item to cost, then click Components.

3. Add Ingredients and Quantity

       Select all required ingredients .

      Set QtyMade based on expected output.

      For each ingredients input QtyUsed based on QtyMade amount.

4. Adjust Unit of Measure (UM)

      If UM differs between receiving and costing, double-click UM to adjust.

5. Calculate Cost

       The system will auto-calculate the cost per finished product.

6. Set Price

       Close, then click the Price column to edit.

7. Ready for Transaction
