Signatures


The Signatures button is in the header window of the transactions (next to Print Receipt). It sets the names printed on the signature lines of the receipt. Each module has its own Signatures entry in the menu and in Access Rights (for example Sales Signatures, Receiving Signatures).

 

Easy Steps:

 

1. Open the header window of the transaction (RightClick the receipt->Edit, or the header window when saving).

2. Click Signatures

3. Click New

    Fill-in textboxes: SignLabel (ex. Prepared by), SignName, SignPosition, SignLine

4. Click Save

 

...to change or remove a signature: select it, then click Edit / Delete.
