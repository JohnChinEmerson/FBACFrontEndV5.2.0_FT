Logging In


Easy Steps:

 

1. Open the system address in the browser (computer, tablet or phone).

2. Select Branch (or Super Admin).

3. Input Username and Password (tick Show password to see what you type).

4. Select Edition (hosted system only). DEFAULT uses the edition of your user account.

5. Tick Remember me to keep the branch, edition and username on this device. The password is never kept.

6. Click Login.

 

After login the Dashboard is shown. On a phone the system opens straight on the Login screen.
