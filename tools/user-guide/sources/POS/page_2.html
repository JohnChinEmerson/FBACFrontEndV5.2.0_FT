1. How to add item?


Easy Steps:

 

1. Click Files->Items

2. Click New button

3. Add ItemType

     Click New button

     Fill in textboxes

         ItemType (ex. Finish Product, Ingredients, Set, Ad-ons, etc.).

         ForSale - no if item is not for sale.

         HasInventory - no if qty is not inventoried.

         Set - no if item is not set.

     Click Save.

4. Fill-in textboxes 

     Alias- name display in sales transaction.

    Cost - supplier price.

    Price  - selling price.

    HasInventory - no if qty is not inventoried.

    Consumable - no if item is a fixed asset.

    AlertQty - out of stock set quantity.

5. Click Save
