Inventory stocks


Easy Steps:

 

1. Click Inventory->Inventory Stocks

2. At the second tab->Select Category->View Stocks

3. Click New Inventory->Click confirmation->Yes (the selected category transferred to the 1st tab)

4. At the first tab->Select Category->Click View

5. Print Stocks (pls goto the ceiling area to physically count the item and record it under physical count column)

6. Using the printed copy, type under physical account column and press enter.

7. Once all the physical count were inputted, click Add to Finish.
