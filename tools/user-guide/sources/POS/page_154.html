Sales Return


Easy Steps:

 

1. Click Returns->Sales Return Transaction

2. Search Customer

3. Click Go

4. Search Item->Press Enter

5. Input Quantity->Press Enter

6. Input Reason

...repeat the process until all items are entered.

...right click the item to add serialnos, edit/remove (second tab)

7. Click Save-F4

8. Select PaymentType

9. Click Save
