Tables


    A. Click Files->Tables

    • View - to view tables
    • New - to add new table

 

    B. This allows you to view the tables associated with a specific table category, but only if the file configuration setting for "MultipleArea" is yes.

 

    C. How to add new table?

        Easy Steps:

1. Click Files->Tables

2. Click New button

3. Fill in the Table Details

      TableCategory - if file config multiplearea is yes.

      No. of Tables - Enter the total number of tables to display in the sales transaction.

      Start count - Enter the starting number for generating tables (e.g., "1" to begin counting from 1).

      Table Suffix - Enter a label or suffix for the tables, such as "TableNo" or "PriorityNo".

5. Click Save

 

D. How to delete all table?

     Easy Steps:

1. Search Table

2. RightClick->Select delete all
